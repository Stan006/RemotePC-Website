1. Overview

RemotePC consists of an Android controller, a Windows listener, and this website. All remote control communication occurs directly between your devices over your local network.

2. Data collection

The RemotePC Android app uses Firebase Analytics to collect limited, anonymous usage data such as feature interactions, and basic app performance information.

This data is used solely to understand how the app is used and to improve stability and usability.

  • No personal information is collected
  • No advertising identifiers are used
  • No data is sold or shared for marketing purposes
  • No remote control data passes through our servers

3. Android permissions

  • INTERNET — Local network communication
  • ACCESS_WIFI_STATE — Network status detection
  • Storage (optional) — File transfer features

4. Website & analytics

This website may use basic analytics to measure anonymous traffic volume. No personal data is collected, and no tracking is performed across sites.
