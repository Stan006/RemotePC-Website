Android App

Client · Controller

The app you install on your phone or tablet. It finds and connects to a Windows Listener on the same local network so you can view and control that PC.

Requires: local network access (Wi-Fi/LAN) to discover and connect to nearby devices. If you downloaded it from Google Play, your use of that store is also governed by Google Play's own terms.

Windows Listener

Host

Runs on the PC you want to access remotely. It listens for incoming connections from the Android App and holds the security controls that decide who's allowed to connect.

Carries: the local security features below — IP whitelisting, IP banning, a client connection limit, and encryption of certain data such as clipboard content.

Also connects to: Google Firebase, for exactly two always-on, fully anonymous purposes — receiving broadcast messages from us and sending an anonymous "how many people are using RemotePC right now" ping. Neither can be turned off. See Section 9.

9. Privacy & Data Collection

We try to collect as little as possible.

  • Session data: the current version of the Windows Listener doesn't create or keep local logs of remote-control sessions.
  • Update checks: RemotePC may contact GitHub's public API to check for new versions. Like any internet request, this sends your device's IP address to GitHub, which processes it under GitHub's own privacy statement — we don't receive or store it. Nothing else is transmitted for this purpose.
  • Broadcast channel (Firebase): the Windows Listener keeps a persistent, one-way connection to Google Firebase so we can push broadcast messages — announcements, security notices, and similar updates — to users. This is a fixed part of how the Windows Listener is built; there's no in-app or config-file setting to turn it off.
  • Anonymous usage ping (Firebase): the Windows Listener also sends a periodic ping to us via Firebase so we can see how many people are using RemotePC at a given time. The ping is fully anonymous — it isn't linked to an account, name, email, or anything else that could identify you, your device, or your network — and, like the broadcast channel, it can't be turned off.

Other than the GitHub update check and these two Firebase connections, RemotePC makes no other connection to us. Full details — including our legal basis for the Firebase connections and your right to object — live in our standalone Privacy Policy. If you're in the EEA/UK, you generally have rights to access, correct, delete, or restrict use of your personal data, and to complain to your local data protection authority.
